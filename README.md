# 你的理想恋爱剧本

从向往的开场、约会方式、相处节奏到未来想象，匹配你骨子里最想要的恋爱故事类型。

## 包含内容
- `index.html`：完整测试页面（HTML / CSS / JavaScript 全部内联在单个文件中）。

## 结果类型
- 青梅竹马型
- 双向奔赴型
- 欢喜冤家型
- 细水长流型
- 浪漫童话型
- 并肩打拼型
- 灵魂伴侣型

## 如何使用
1. 解压后双击打开 `index.html`，即可在浏览器中直接答题，无需安装环境、无需后端。
2. 共 40 道单选题，答完自动评分并展示结果；结果页支持重新测试。
3. 页面已做响应式适配，手机和电脑浏览器均可正常使用。

## 部署到静态托管（可选）
本项目为纯静态页面，可直接上传到任意静态托管，例如 GitHub Pages、Vercel、Netlify、对象存储等：
- 将 `index.html` 放在仓库根目录并开启 Pages，即可通过公开链接访问。
- 若替换仓库内同名文件，刷新页面即可看到新版本。

## 说明
- 本测试为趣味娱乐与自我参考，结果不构成专业心理诊断，也不构成婚恋、择偶或相处建议。
- 题目与选项均为生活化情境设计，不考查心理学专业知识。
- 恋爱人格、吸引类型与适配度结果仅作轻松参考，真实关系仍需靠双方沟通与经营。
